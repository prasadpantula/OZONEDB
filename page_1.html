1 Project Overview

The OZ ONE Unified System is a full-featured, browser-native environmental monitoring dashboard built to replicate and extend Power BI's interactive analytics experience without requiring any Microsoft licensing or desktop software. It provides real-time-style ozone (O₃) air quality monitoring across two industrial regions in the Kingdom of Saudi Arabia: Jubail and Dammam.

The dashboard was converted from a knowledge-base HTML file (embedded inside a DOCX OLE object) into a fully structured React application with multi-page navigation, cross-filtering, drill-down hierarchies, live KPI cards, and alerting — mirroring the key interaction paradigms of Microsoft Power BI Desktop.

Monitoring Scope

9 air quality monitoring stations across Jubail (5) and Dammam (4) regions, reporting O₃, NOₓ, VOC, temperature, wind, and humidity.

WHO Compliance Tracking

Real-time comparison against the WHO O₃ standard of 120 µg/m³ (8-hour rolling average), with visible reference lines on every chart.

Drill-Down Analytics

3-level drill-down hierarchy on the main dashboard: Region → Station → Hourly profile, mimicking Power BI's visual drill mode.

Alert Management

Active alert queue with severity tiers (INFO / WARNING / DANGER / CRITICAL), acknowledgment workflow, and health impact guide.

3.3 Data Layer

All data is defined in src/data/index.ts as typed TypeScript constants. There is no backend API — the dashboard is a fully self-contained static SPA. The data mirrors the original OZ ONE HTML dashboard values exactly. Replacing the constants with live API calls requires only swapping the import source.

Data Sources in the Original System The original OZ ONE dashboard (embedded in the DOCX file) references data from RCEC (Regional Center for Environmental Consultancy) and PME (Presidency of Meteorology and Environment, Saudi Arabia). The status bar footer displays "Data source: RCEC / PME".

6 Global Slicer Controls

The top header bar contains two global slicers that affect all pages simultaneously:

SlicerOptionsEffect
Region Slicer All Regions / Jubail / Dammam Filters which region's data series are shown on the 24h trend, weekly pattern bar chart, and KPI cards. Defaults to "All Regions".
Time Range Slicer 24h / 7d / 30d / 1y Controls the time window of the 24-hour trend chart on the Dashboard page. The 24h option shows all 24 hourly data points; other options sample the data accordingly. Defaults to "24h".

Slicer state is managed in App.tsx using React useState hooks and passed down as props to each page component, ensuring all pages respond immediately to any slicer change without a page reload.

7.4 Dark Theme

The dashboard uses a dark-mode-first theme set via <html class="dark"> in index.html. The Tailwind v4 .dark CSS block provides all dark token overrides. The background is deep navy (oklch(0.12 0.025 228)) with card surfaces at oklch(0.16 0.028 228), creating visual depth between layers.
